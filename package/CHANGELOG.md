# Changelog

## 1.3.0

- Config menu in English, or Polish when the game is set to Polish.
- Config file keys are now English and stay the same in every language. Settings from older versions reset to defaults.
- On-screen messages and the `pinezki` command follow the game language too.

## 1.2.0

- New pin names, plain names in the config menu.
- Mushrooms are back with their own toggle (off by default).
- Random notes on pins (e.g. `miedz ruda - check later`) and on F7 for unknown objects.

## 1.1.0

- Per-item toggle in the config (e.g. only blueberries or only copper).
- Wild beehives.
- Regular mushrooms and dandelions removed, too much map clutter.
- Default grouping radius 40 m instead of 20 m.

## 1.0.0

- First release: automatic pins for bushes, ores, dungeons and locations.
- Crossing out picked bushes, F7 / F8, `pinezki` command.
